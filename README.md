# Student Achievement Showcase

This is a simple website made using HTML and CSS.

The website shows student achievements, projects and hackathon participation.

## Files in this project

1. achievements.html - Shows student achievements.
2. projects.html - Shows different student projects.
3. hackathons.html - Shows hackathon participation.

## Technologies Used

- HTML
- CSS

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open achievements.html in a browser.
4. Click on the navigation links to visit other pages.

## Purpose

The purpose of this project is to practise HTML, CSS and GitHub.
